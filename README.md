One funny line for the make.fun bounty "The One-Line Laugh" — a single sentence about the laptop that only panics when procrastination ends.

> My laptop fan only screams when I open the one document I've been avoiding all day.

## Run

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
